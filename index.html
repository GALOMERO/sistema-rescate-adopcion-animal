Bienvenidos

Este prototipo permite organizar la información básica de los casos de animales que necesitan ayuda. Su propósito académico es mostrar cómo se estructura un sitio web mediante etiquetas semánticas de HTML5.

Funciones del sistema

Registro de reportes

Permite ingresar información de un animal que requiere atención o rescate.

Ir al formulario de reporte

Consulta de casos

Presenta una tabla demostrativa con reportes y el estado de cada caso.

Consultar la lista de rescates

¿Cómo funciona el prototipo?

  1. La persona ingresa al formulario de reporte.
  2. Completa los datos solicitados y revisa los campos obligatorios.
  3. Consulta la página de rescates para observar el formato de los registros.

Alcance académico

Esta versión utiliza únicamente HTML5. No incorpora hojas de estilo CSS, programación JavaScript ni conexión con una base de datos. Por este motivo, los datos del formulario no se almacenan de manera permanente.

Proyecto académico de maquetación estructural HTML5.
