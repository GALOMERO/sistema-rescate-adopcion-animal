# Evidencias de tu ejecución

Antes del commit de documentación:
1. Captura el repositorio público con URL y selector de ramas. Guarda `01_repositorio.png`.
2. Captura `git log --graph --oneline --decorate --all` mostrando fusiones y ramas. Guarda `02_historial.png`.
3. Ejecuta la demo y las diez pruebas; captura el resultado real. Guarda `03_ejecucion.png`.
4. En Word, reemplaza los marcadores del apartado Evidencias con esas capturas y agrega el enlace real.
5. Exporta el documento a PDF reemplazando `docs/Actividad_1.pdf` y guarda el DOCX.

No se incluyen capturas ficticias. La captura del historial puede corresponder al cierre del avance 3, con el avance 4 en preparación; debe describir el momento real. El historial definitivo se verifica después de publicar la release.
